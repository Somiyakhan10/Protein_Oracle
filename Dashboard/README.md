# 🧬 ProteinOracle — Enzyme Function Predictor

[![HuggingFace Space](https://img.shields.io/badge/🤗-HuggingFace%20Space-blue)](https://huggingface.co/spaces)

> Predict enzyme class from raw amino-acid sequence using ESM-2 protein language model embeddings, a trained Random Forest classifier, and SHAP-based explainability.

---

## 🔬 What It Does

1. Accepts a protein sequence in plain single-letter or FASTA format
2. Generates a **320-dimensional embedding** via `facebook/esm2_t6_8M_UR50D`
3. Appends **21 hand-crafted features** (sequence length + 20 amino-acid frequencies)
4. Classifies using a **Random Forest** trained on 198 reviewed UniProt sequences
5. Optionally computes **SHAP values** to explain individual predictions

---

## 🏷️ Enzyme Classes

| Class | Function |
|---|---|
| ⚡ Kinase | Transfers phosphate groups to substrates |
| 🔵 Phosphatase | Removes phosphate groups via hydrolysis |
| ✂️ Protease | Cleaves peptide bonds in proteins |
| ⚗️ Dehydrogenase | Catalyzes oxidation–reduction reactions |
| 🔄 Transferase | Transfers functional groups between molecules |

## 🏋️ Training Your Own Model

Run `train_and_save.py` to:
- Fetch 198 reviewed human enzyme sequences from the UniProt REST API
- Generate ESM-2 embeddings for each sequence
- Train a Random Forest classifier
- Save `rf_model.joblib` and `scaler.joblib`

```bash
python train_and_save.py
```

Expected output:
```
Fetching Kinase...   downloaded 40 sequences
...
5-fold CV accuracy: 0.66 ± 0.04
✓ Saved rf_model.joblib and scaler.joblib
```

> **Note:** This takes ~5–10 minutes on CPU due to ESM-2 embedding generation.

## ⚙️ Technical Details

| Component | Detail |
|---|---|
| Protein LM | `facebook/esm2_t6_8M_UR50D` (8M parameters) |
| Embedding | Mean-pooled last hidden state (320-dim) |
| Additional features | Sequence length + 20 AA composition frequencies |
| Classifier | Random Forest (100 trees, sklearn) |
| Explainability | SHAP KernelExplainer (optional, ~30-60 s) |
| Training data | 198 reviewed human proteins from UniProt |
| CV accuracy | 66% (5-fold, 5 classes) |
| Max sequence length | 1024 residues (ESM-2 truncation) |

## ⚠️ Limitations

- Trained on only 198 sequences — use predictions as a **hypothesis generator**, not a definitive annotation
- Only classifies 5 enzyme families; sequences from other classes will be misclassified
- ESM-2 embedding quality degrades for sequences shorter than ~50 residues
